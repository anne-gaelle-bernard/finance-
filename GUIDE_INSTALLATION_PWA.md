# 📱 Guide d'installation de Finance Tracker (PWA)

## Qu'est-ce qu'une PWA ?

Finance Tracker est une Progressive Web App (PWA). Cela signifie que vous pouvez l'installer sur votre appareil et l'utiliser comme une application native, même sans connexion internet (certaines fonctionnalités).

## 💻 Installation sur ordinateur (Windows, Mac, Linux)

### Google Chrome / Microsoft Edge / Brave

1. Visitez l'application : https://finance-tracker-git-main-anne-gaelle-bernards-projects.vercel.app/
2. Une bannière apparaîtra automatiquement vous proposant d'installer l'application
3. Cliquez sur "Installer l'application" dans la bannière

**OU**

1. Cliquez sur l'icône d'installation (⊕) dans la barre d'adresse à droite
2. Cliquez sur "Installer"
3. L'application sera ajoutée à votre système

### Firefox

1. Visitez l'application
2. Cliquez sur le menu (☰) en haut à droite
3. Sélectionnez "Installer cette application"

## 📱 Installation sur mobile

### Android (Chrome)

1. Ouvrez l'application dans Chrome : https://finance-tracker-git-main-anne-gaelle-bernards-projects.vercel.app/
2. Une bannière apparaîtra vous invitant à installer l'application
3. Appuyez sur "Installer"

**OU**

1. Appuyez sur le menu (⋮) en haut à droite
2. Sélectionnez "Ajouter à l'écran d'accueil" ou "Installer l'application"
3. Confirmez l'installation

### iOS (Safari)

1. Ouvrez l'application dans Safari : https://finance-tracker-git-main-anne-gaelle-bernards-projects.vercel.app/
2. Appuyez sur le bouton de partage (□↑) en bas de l'écran
3. Faites défiler et sélectionnez "Sur l'écran d'accueil"
4. Nommez l'application et appuyez sur "Ajouter"

## ✨ Avantages de l'installation

- 🚀 **Accès rapide** : Lancez l'application directement depuis votre écran d'accueil
- 📴 **Utilisation hors ligne** : Consultez vos données même sans connexion
- 🎨 **Expérience native** : Interface en plein écran, comme une vraie application
- 🔔 **Notifications** : Recevez des alertes pour vos finances (à venir)
- 💾 **Légère** : Prend moins d'espace qu'une application native

## 🔄 Mise à jour

L'application se met à jour automatiquement lorsque vous êtes connecté à Internet. Vous n'avez rien à faire !

## ❌ Désinstallation

### Sur ordinateur
- Cliquez droit sur l'icône de l'application
- Sélectionnez "Désinstaller" ou "Supprimer"

### Sur mobile
- Maintenez l'icône appuyée
- Sélectionnez "Supprimer" ou "Désinstaller"

## 🆘 Besoin d'aide ?

Si vous rencontrez des problèmes lors de l'installation, ouvrez une issue sur GitHub ou contactez le support.
